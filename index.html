Token de GitHub para sincronizar

Creá un fine-grained personal access token. Enlace directo:
→ Crear token para este repo

El orden del formulario importa:
1. Acceso al repositorio → marcá Only select repositories y elegí Faena (de FeedlotSF). Sin esto NO aparecen los permisos de repositorio, y menos "Contenido".
2. Subí la vista: en Repository permissions (arriba de los de cuenta, donde están "block another user", "copilot", etc.) buscá "Contenido" / "Contents" → Read and write.
3. Elegí expiración y tocá Generate token. Pega el token acá debajo.
Alternativa más simple (recomendada si traba): usá un token clásico: tu foto → Settings → Developer settings → Personal access tokens → Tokens (classic) → Generate new token (classic) → marcá la casilla repo → Generate. Funciona igual en esta app.
El token se guarda solo en este navegador (nunca se sube al repo).
